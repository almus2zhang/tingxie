# 单词听写兼记忆大师 (TingXie Vocab Master)

一个现代化、功能完备的英语单词听写与卡片记忆 Web 网站。支持**权威真人纯正发音**、**文本批量导入**与**手机/截图拍照 AI 智能识别**（基于硅基流动 SiliconFlow 视觉大模型）、**候选总词库自定义挑选**、**顺序听写与即时批改**、**双语经典例句**以及**麦克风录音跟读比对打分**。

---

## ✨ 核心功能亮点

1. **准确纯正发音**
   - 接入权威官方原声真人发音（支持美音 US / 英音 UK 随时切换）。
   - 音质纯正自然，彻底摒弃机械合成电音。
   - 例句支持朗读跟读，单词发音毫秒级响应与本地缓存。

2. **多模态单词导入**
   - 📷 **拍照 / 图片 AI 智能识别**：手机拍照、上传图片或直接按 `Ctrl + V` 粘贴截图，调用**硅基流动 (SiliconFlow) 多模态视觉大模型**（如 `Qwen2-VL-72B-Instruct` 等），自动高精度提取图片中所有英文单词、音标、释义及例句。
   - 📝 **文本批量导入**：支持一键粘贴单列单词列表或带中文释义的列表，支持 AI 智能自动补全音标与双语例句。
   - 识别后支持表格预览与直接纠错，确认后持久化至数据库。

3. **候选总词库与词单管理**
   - **候选总词库**：集中管理所有词汇，支持全文搜索、音标查阅、发音试听、多选勾选。
   - **自由组建**：勾选任意单词后，可一键“加入指定词单”、“开启听写”或“开启记忆”。
   - **服务端持久化**：采用轻量级高性能 SQLite 存储，自动保存词单结构、学习正误记录与发音最高分。

4. **沉浸式顺序听写模式 (Dictation)**
   - 自动按顺序播放目标单词发音。
   - 专注大字号拼写输入框，自动对焦。
   - 支持词长与首字母提示辅助。
   - 按 `Enter` 提交核对：即刻揭晓单词正确拼写、音标、中文释义与例句，判定正误并伴有反馈音效与彩带特效。
   - 再次按 `Enter`（或点击下一个）无缝切入下一个单词并自动发音，体验丝滑流畅。
   - 测试结束后生成**听写总结报告**，支持一键单独重练所有拼错生词。

5. **卡片记忆与录音打分 (Memory & Speech Scoring)**
   - **三种视角自由切换**：“仅显示单词（考释义）”、“仅显示释义（考拼写）”、“全部显示”。
   - 支持键盘左右方向键 `←` / `→` 翻页，空格键翻转卡片。
   - **双语例句**：提供典型生动的高频例句与中文对照翻译。
   - 🎙️ **发音录音比对打分**：点击麦克风跟读，结合语音识别与音素编辑距离算法智能比对打分（0-100分），给出如“地道纯正”、“重音需调整”等具体发音反馈。

## 🚀 快速启动

### 方式一：一键直接启动（生产一体化）
```bash
npm start
```
访问浏览器：`http://localhost:5000`

### 方式二：开发调试模式
```bash
# 终端 1：启动后端服务 (端口 5000)
npm run server

# 终端 2：启动前端 Vite 开发服务器 (端口 5173，自动热重载与接口代理)
npm run client
```
访问开发前端：`http://localhost:5173`

## ⚙️ 硅基流动 (SiliconFlow) API Key 配置

1. 打开网站，点击右上角导航栏的 **⚙️ 设置** 按钮（或点击提示标签）。
2. 在弹出框中填入您的硅基流动 API Key（如 `sk-...`），点击保存。
3. 您还可以自由选择视觉模型（如 `Qwen/Qwen2-VL-72B-Instruct` 推荐、`Pro/Qwen/Qwen2-VL-7B-Instruct` 等）、偏好口音（美音/英音）及自动发音开关。
